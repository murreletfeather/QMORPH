# QMorph 网格处理系统

## 项目简介

QMorph 是一个用于三角网格到四边形网格转换的工具，支持命令行和图形界面两种模式。项目实现了 QMorph 算法，可用于科学计算、有限元分析等领域的网格生成与优化。

## 主要功能

- 支持加载、编辑和保存三角网格（.mesh 文件）
- 支持将三角网格自动转换为四边形网格（.dta 文件）
- 提供图形用户界面（GUI）进行可视化操作
- 支持命令行批处理，无需启动 GUI
- 支持网格导出为 LaTeX 绘图格式

## 构建与运行

本项目基于 Java 21 和 Maven 构建。

### 构建

1. 安装 JDK 21 及以上版本。
2. 安装 Maven。
3. 在项目根目录下执行：
   ```sh
   mvn clean package
   ```
   生成的 jar 包位于 `target/qmorph-1.0-SNAPSHOT.jar`。

### 运行

- 启动 GUI 并加载网格文件：
  ```sh
  java -jar target/qmorph-1.0-SNAPSHOT.jar yourmeshfile.mesh
  ```
- 命令行无界面批处理：
  ```sh
  java -jar target/qmorph-1.0-SNAPSHOT.jar -noGUI yourmeshfile.mesh
  ```
  结果将输出到 `qmesh.dta` 文件。
- 查看帮助：
  ```sh
  java -jar target/qmorph-1.0-SNAPSHOT.jar -help
  ```

# 文件格式说明

## .mesh 文件（三角网格输入）

- 每一行表示一个三角形，包含三个顶点的坐标。
- 每个顶点用 (x, y) 表示，一行共 6 个数字，格式如下：

```
x1, y1, x2, y2, x3, y3
```

示例：

```
0.0, 0.0, 1.0, 0.0, 0.5, 1.0
1.0, 0.0, 1.5, 1.0, 0.5, 1.0
```

## .dta 文件（四边形/三角形网格输出）

- 每一行表示一个网格单元，可以是三角形或四边形。
- 三角形：6 个数字（3 个点）
- 四边形：8 个数字（4 个点）

四边形格式：

```
x1, y1, x2, y2, x3, y3, x4, y4
```

三角形格式：

```
x1, y1, x2, y2, x3, y3
```

示例：

```
0.0, 0.0, 1.0, 0.0, 1.0, 1.0, 0.0, 1.0   // 四边形
1.0, 0.0, 1.5, 1.0, 0.5, 1.0             // 三角形
```
